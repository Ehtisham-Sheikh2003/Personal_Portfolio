Projects

  • Course Registration System

    This full-stack student course registration system represents a comprehensive web application developed using modern web technologies with a three-tier architecture. The frontend interface is meticulously crafted with HTML, CSS, and JavaScript to deliver an intuitive and responsive user experience across all role-based dashboards. For the backend infrastructure, the system employs PHP implemented according to the Model-View-Controller (MVC) architectural pattern, ensuring clean separation of concerns, maintainable codebase, and streamlined development workflows. Microsoft SQL Server serves as the robust database management system, providing efficient data storage and retrieval capabilities for all academic operations. The application is hosted on an XAMPP web server environment, which provides the necessary Apache, PHP, and database integration for seamless local development and testing. The system incorporates three distinct user roles with specialized permissions: Administrators possess comprehensive privileges to create course sections, adjust class capacities, and manage student records within the system. Academic Advisors function as intermediaries, specifically tasked with reviewing, accepting, or declining student registration requests while maintaining communication channels with administration. Students interact directly with their assigned advisors, submitting registration requests and managing their academic schedules through a personalized portal. The platform features secure login and signup mechanisms with robust user authentication protocols to ensure data protection and role-based access control. All CRUD (Create, Read, Update, Delete) operations are fully implemented throughout the application, enabling dynamic data management across all entities. The system demonstrates real-time data processing capabilities, ensuring immediate reflection of registration changes, advisor approvals, and administrative modifications without requiring page refreshes, thereby providing an efficient and professional academic management solution for educational institutions.

  • Calculator

    This responsive calculator is a fully functional, front-end project meticulously engineered with core web technologies: HTML for structure, CSS for presentation, and vanilla JavaScript for logic and interactivity. It is designed to be a comprehensive digital tool that not only performs standard arithmetic operations but also incorporates advanced features for managing a dynamic calculation history, elevating it beyond a simple computational widget. The application features a clean, intuitive, and modern user interface built with a mobile-first approach. The responsive design ensures a seamless and optimal user experience across a wide spectrum of devices, from compact mobile phones and tablets to large desktop monitors. The layout automatically adapts using CSS Flexbox/Grid and media queries, with buttons resizing appropriately and the display remaining clear and legible on any screen size. Its core functionality encompasses all fundamental arithmetic operations—addition, subtraction, multiplication, and division—supporting complex expressions with decimal points and sequential calculations. The JavaScript engine is built to handle operator precedence and immediate execution logic, providing users with accurate results in real-time.
